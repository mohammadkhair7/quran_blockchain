Unzip file containing executables and _internal subfolder

Blockchain Encryption Usage:  Encrypt by loading an excel file containing names and numbers of Suras, and Ayas (in utf8 format) 
and their order from start of suras
takes 30-60 min to encrypt and produces a file called Quran_77432_utf8.json file
>> quran_blockchain_doc_utf8.exe 
Enter name of excel file with Suras and Ayas to blockchain encrypt, 
 columns (sura_number, aya_number, aya_text, page_number, mekki_madani): Quran_77432.xlsx

Generates Quran_77432_utf8.json
